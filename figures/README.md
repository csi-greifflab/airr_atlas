# AIRR Atlas — Figure reproduction guide

Single reference for all manuscript figures. Paths below are relative to the repository root unless noted.

All filenames use lowercase `fig_` and `s` prefixes (e.g. `fig_3a_…`, `fig_s5_…`).

Many figures share the same analysis pipelines — those pipelines are documented once in [Shared pipelines](#shared-pipelines), and individual figures link back to them.

**Prerequisites:** conda environment from `airr_atlas.yml`. Large embedding files live outside git under `data/` (see [Data requirements](#data-requirements)).

---

## Shared pipelines

### Pipeline 1 — Global repertoire structure (Figure 2, Supplementary S1–S4, S11–S13)

Used for embedding extraction, t-SNE, completeness/W₂ analysis, and related supplementary figures (including S16).

All code lives in `figures/main/fig_2_w2_distance_matrices/`.

| Step | Script | Driver |
|------|--------|--------|
| AntiBERTa2 (AB2) embeddings | `scripts/antiberta2_cdr3.py` | `drivers/run_antiberta2_cdr3.bash` |
| ESM2 embeddings | `scripts/esm2.py` | `drivers/run_esm2.bash` |
| One-hot (OHE) embeddings | `scripts/OHE_script.py` | `drivers/run_ohe.bash` |
| t-SNE reduction | `scripts/build_tsne.py` | `drivers/run_tsne.bash` |

### Pipeline 2 — Antigen specificity & Vicinity (Figures 3–4, Supplementary S6–S10, S14–S15)

Wasserstein distance, t-SNE density, and Vicinity (spatial homogeneity) analyses.

Core scripts and notebooks live in `figures/main/fig_3_antigen_specificity/`. Figure 4 drivers and plotting notebooks live in `figures/main/fig_4_vicinity_analysis/`.

#### Embedding extraction

| Script | Description |
|--------|-------------|
| `fig_3_antigen_specificity/drivers/run_PEPE.sh` | Embedding extraction via `pepe-cli` |
| `fig_3_antigen_specificity/notebook/PREPROCESSING.rmd` | Dataset preprocessing |

#### Wasserstein-2 distance (Figure 3A, Supplementary S6)

| Script | Description |
|--------|-------------|
| `fig_3_antigen_specificity/scripts/get_W2.py` | Core W₂ computation |
| `fig_3_antigen_specificity/scripts/W2_antigen-specific.py` | Antigen-specific W₂ heatmaps |
| `fig_3_antigen_specificity/scripts/LD_pairwise_AG.py` | Pairwise Levenshtein distances (Supplementary S6) |

#### t-SNE density (Figures 3B–3C, Supplementary S7)

| Script | Description |
|--------|-------------|
| `fig_3_antigen_specificity/scripts/fit_transform_TSNE_fig3.py` | Fit t-SNE on iReceptor, project other datasets |
| `fig_3_antigen_specificity/notebook/tsne_density_plot_script.Rmd` | Density difference and antigen density plots |

#### Vicinity analysis (Figure 4, Supplementary S8, S10, S14, S15)

| Script | Description |
|--------|-------------|
| `fig_4_vicinity_analysis/scripts/get_LD_matrix.py` | Levenshtein distance matrices (Vicinity input) |
| `fig_4_vicinity_analysis/scripts/Vicinity_pipeline_final.py` | Core Vicinity pipeline |
| `fig_4_vicinity_analysis/scripts/Vicinity_analysis_class_final.py` | Class supporting the Vicinity pipeline |
| `fig_4_vicinity_analysis/notebooks/Vicinity_plots_script.rmd` | Vicinity and supplementary layer plots |

Dataset batch drivers (Figure 4). All drivers source `driver_env.sh`, which resolves repo-relative paths via `AIRR_ATLAS_ROOT` (defaults to repo root). Activate the `airr_atlas` conda env before running. Precompute LD matrices with `get_LD_matrix.py` into `fig_4_vicinity_analysis/data/results/ld/`. Large embeddings live under repo-root `data/embeddings/`.

| Driver | Dataset | LD matrix (under `data/results/ld/`) |

| `run_CHINERY.sh` | Trastuzumab (TZ) | `tz_LD_dist_mat_HB_LB.npy` |
| `run_COVABADB.sh` | CoV-AbDab | `LD_covabdab_bg2.npy` |

| `run_POREBSKI.sh` | Porebski DMS | `porebski_LD_matrix.npy` |

## Folder layout

```
figures/
├── README.md                          ← this file
├── main/
│   ├── fig_1_abstract/                output PNG
│   ├── fig_2_w2_distance_matrices/    Pipeline 1: scripts, drivers, notebooks, data
│   ├── fig_3_antigen_specificity/     Pipeline 2: scripts, notebooks, data, output
│   └── fig_4_vicinity_analysis/       Fig 4 drivers, notebooks, data, output
└── supplementary/
    ├── fig_s3/ … fig_s17/             notebooks/, data/, output/
```

Figure folders hold **outputs, notebooks, and figure-specific data**. Shared analysis code is grouped under the pipeline folders above (primarily `fig_2_*` and `fig_3_*`), not duplicated per supplementary figure.

## Data requirements

| Location | Contents |
|----------|----------|
| `figures/main/fig_2_w2_distance_matrices/data/` | Small CSVs (e.g. `data_for_figure_2c.csv`); full embeddings under repo-root `data/` |
| `figures/main/fig_3_antigen_specificity/data/` | Sample sequences and metadata; full embeddings under repo-root `data/embeddings/` |
| `figures/main/fig_4_vicinity_analysis/data/` | Vicinity sample sequences, metadata, and pre-computed results |
| Repo-root `data/` | Large files (gitignored): embeddings, completeness CSVs, and full FASTA inputs |

Obtain or generate embedding files locally and place them under `data/embeddings/` before running Pipeline 2 scripts and Figure 4 drivers.
